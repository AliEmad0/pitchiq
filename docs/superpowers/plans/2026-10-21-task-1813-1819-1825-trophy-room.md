# Trophy Room + Scouted Tactical Style Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `/game/trophies` (Album + Hall of Fame) and a scouted tactical-style pick on the pre-match screen.

**Architecture:** Style is a new optional field of the match's identity (`RivalSetup.style`), absent = the shipped uniform draw, so every old save and v2 link replays byte-identically; present = the coach's pick against an opponent style drawn from that XI's tendency. Album and Hall of Fame are IndexedDB stores filled by ONE best-effort `recordFullTime` called from every full-time path, with achievements as pure `domain/` predicates and club-season set lists served by a prerendered static route.

**Tech Stack:** Next.js App Router (force-static), React 19, TypeScript, next-intl (en + ar), raw IndexedDB, Vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-20-task-1813-1819-1825-trophy-room-design.md`

## Global Constraints

- Every new route is `force-static` with `revalidate = false`; dynamic segments `dynamicParams = false` (no request-time work — owner: never move cost onto Fluid Active CPU).
- `domain/` stays pure: no I/O, no `Math.random()`, no `Date.now()`; seeded `mulberry32` only. `adapter/` is `server-only` and never imported by client code.
- Style odds: the opponent's tendency with probability **0.6**, each of the other five **0.08**. Edge size stays `EDGE_ATTACK = 8`.
- A v2 share code and a `SavedMatch` without `style` replay under the OLD rule (both styles from the uniform `chaosMatchup` draw) — byte-identical.
- Picker only in **single-match** format on `/game/draft`, `/game/chaos` and the drafted packs (budget, chemistry, legacy, captains, nation); hidden for `?format=season`, the daily, Classic, Survival, What-If. Default pick: Balanced, or the last pick (localStorage, try/catch).
- `DB_VERSION` 4 → 5; new stores `album`, `trophies`, `trophyLog`. Persistence is best-effort: nothing may throw into a full-time screen.
- Not collected: What-If XIs, and a shared link someone else sent. Match-level badges only from matches the coach PLAYED; season badges read whole runs. Champions/Invincibles: full league runs only (Legacy-style seasons + Classic); Survival → Great Escape only.
- Album key = `cardId` + club `teamId`. A set = every card in that club-season's Classic pool (686 sets, 19–39 cards, median 27, 18,653 cards — measured).
- The 16 achievement ids, in this order: `first-win, clean-sheet, thrashing, hat-trick, sparse-hat-trick, comeback, late-winner, ten-men, champions, invincibles, great-escape, daily-7, rewrite, rewrite-all, collector-100, set-complete`.
- Owner's designs: Album #1 Panini Classic, Hall #1 Trophy Cabinet, Style #2 Scout's Dossier (`design/trophy-gallery/index.html`). Motion: hybrid #1 Sticker Slap + #5 Stamp Slam (`design/trophy-gallery/motion.html`). Real crests via `ClubCrest`.
- Motion audit: only `transform`/`opacity`/`box-shadow`, finite, one reduce gate per surface covering every animated selector; tests assert RULES (`selector {` + `animation:`).
- Strings in BOTH catalogs. New namespaces are top-level (`gameStyle`, `gameTrophies`) — two tests assume `game` is flat. User-visible numbers through `localizeDigits`.
- Commands (all via WSL, nvm 22): tests `$HOME/t.sh <files>`; `pnpm type-check`; `CI=true pnpm lint`. Full vitest crashes locally — run the named files.
- Each finished task: TASKS/CLAUDE/README are updated only in Task 10 (doc-sync rule applies to the merge).

## Review Focus

1. **An old link or save:** a v2 code or pre-change `SavedMatch` must replay with the same fingerprint — pinned by a golden captured BEFORE Task 2 (Task 2) and v2-decode tests (Task 3).
2. **StrictMode double effects:** a full-time effect firing twice must not double album counts or badge unlocks — `trophyLog` dedupe test under `<StrictMode>` (Task 8).
3. **IndexedDB unavailable / failing:** the full-time screen still renders and the Trophy Room shows its empty state — tests with `indexedDB` undefined and with a rejecting `idbPut` (Tasks 5, 9).
4. **Season format:** no picker, no style in the season save; a simmed fixture adds cards with `played: false` and unlocks no match badge (Tasks 4, 8).
5. **Arabic:** style names, achievement names and the 60%/8% odds render from the `ar` catalog with Arabic digits (Tasks 4, 9).
